# Movie-Ticket-System
A movie ticket booking system developed as a software engineering course project.

本專案為軟體工程課程期末專題，參考一般電影院線上訂票流程，
實作一套電影訂票系統。系統包含使用者介面、後端服務與資料庫，
讓使用者能完成會員操作、電影訂票、訂票查詢及退票等功能。

---

##  Project Overview

本專案的主要目標是透過實際系統開發，練習從需求分析、功能設計、
資料庫建置到前後端整合的完整軟體開發流程。

系統以前端提供使用者操作介面，後端使用 Python Flask 處理系統邏輯，
並透過 MySQL 儲存會員、電影與訂票相關資料。

---

##  Features

系統主要包含以下功能：

- 使用者登入與註冊
- 電影資訊瀏覽
- 電影訂票
- 訂票資料查詢
- 退票功能
- 會員服務
- 前後端資料傳遞
- 資料庫資料管理
- 輸入資料與重複資料驗證
